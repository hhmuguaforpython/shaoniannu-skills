# 复刻强度三档

> 这是本 skill 最重要的一个参数。**不选档位就动笔，默认会写成中度。**

同一份原稿，用不同强度复刻，产出的文章可以差到无法互换使用场景。
下面三档是实测出来的（见 `rewritten/` 两版产物），不是拍脑袋分的。

---

## 一览

| | **轻度** L1 | **中度** L2 | **重度** L3 |
|---|---|---|---|
| 别名 | 借节奏 | 沉版 | 冲版 |
| 一句话 | 保留原作者的声音，只换呼吸 | 换成少年怒的声音，但情绪压住 | 全盘少年怒，情绪拉满 |
| 感叹号 | 0–3 | 4–10 | **15+**（爆点连打 `！！！`） |
| 金句独段 | 1–2 | 3–8 | **8–15** |
| 段落长度 | 2–5 句 | 1–3 句 | **1–2 句，大量单句成段** |
| 脏字 / TM / 尼玛 | ❌ 不用 | 至多 1 处 | **随意** |
| 点名同行 | 不点名，只说"市面上" | 半点名（鼎某诺） | **半点名 + 下战书** |
| 自吹 | 用事实自吹 | 事实 + 一句宣言 | **直接宣战**（"咱们一个功能一个功能对"） |
| 结构 | 保留原文小标题 | 无编号，空行断章 | **（一）(二)(三) 编号小节** |
| 推销段 | 一小段，克制 | 完整三件套 | **三件套 + 功能清单 + 重复召唤** |
| 标题 | 陈述句 | 陈述句带情绪 | **带 `！！！` 的挑衅句** |
| 典型范文 | —（介于原稿与 04 之间） | `04_letter_to_M_boss` | `01_letter_to_10k_firms`<br>`05_big8_arms_race` |

## 什么时候用哪档

### 轻度 L1 · 借节奏

**只改呼吸，不改人格。** 原作者还是原作者，只是不再写长句、不再堆术语。

适用：
- 原作者已有稳定个人风格，不想被覆盖
- 面向客户 / 合作方 / 投资人
- 技术类干货，怕情绪冲淡专业度
- 官网博客（但 SEO 场景优先用 `blog-rewrite`）

**判据**：读者读完说"这人文笔变利索了"，而不是"这人怎么变了个人"。

### 中度 L2 · 沉版

**换声音，压情绪。** 少年怒的句法和结构，但保留原稿的重量感。

适用：
- 原稿内核是"回望 / 自证 / 复盘"这类沉的东西
- 发在自己号上，但读者里有合伙人、同行大佬
- 想要记忆点，又不想被当成"又一个喊口号的"

**判据**：最有力的句子应该是**安静的**那句（比如「不是活干不完，是没人敢第一个站起来」），而不是感叹号最多的那句。

### 重度 L3 · 冲版

**全盘复刻，情绪拉满。** 这是少年怒本人的默认档。

适用：
- 发在自己号上，读者以一线同行为主
- 目标是转发量、评论区、"这人有意思"
- 有明确的对手要打（竞品 / 大所 / 行业陋习）

**判据**：读者读完想转发给同事并配一句"哈哈哈哈这人敢说"。

⚠ **重度档必须过风险关**，见下。

---

## 重度档的三个风险闸门

写完重度版，发之前逐条过：

**① 半点名的对象是谁？**

少年怒骂的是**大所**（容某、立某、某诚）——大所不会因为一篇公众号找你。
但如果你骂的是**同行软件商**（鼎某诺、审某易），对方是会真找上门的。

→ 同行软件商一律模糊到「某几家老牌审计软件」，攻击性基本不掉。

**② 有没有脏字？**

`他妈` / `TM` / `尼玛` 这类，公众号平台有概率限流。
少年怒自己能用，是因为他号的调性已经立住了。

→ 新号 / 商业号建议全去掉，力度损失很小。

**③ 有没有把吹嘘写成承诺？**

「我们 12 月 31 日之前实现全自动」这种，少年怒敢写是因为他是老板。
如果稿子要过合规，把时间承诺改成方向表述。

## 怎么指定档位

对 Agent：

```
用 shao-nian-nu-style 重写这篇，重度档。
用 shao-nian-nu-style 轻度复刻一下，别太冲。
```

对普通 LLM（在 `prompts/rewrite_prompt.md` 的产品档案里加一行）：

```
复刻强度：重度（L3）
```

**没指定时**：Agent 应当**主动问一句**，或者默认出**中度**并在交稿时说明"这是中度档，要更冲/更淡说一声"。

不要默认出重度——重度是不可逆的，读者看过一次挑衅版，再发沉版会觉得你怂了。

## 一个真实案例

原稿：《把我十年的上市公司审计经验，做成一个可以干活的 Ai 审计工作台》（公众号「激动小航」）

同样的事实（天健十年 / SmartExcel / VLM-OCR / 预审检查 / 普华永道 120 亿），两档产出：

| | 中度（沉版） | 重度（冲版） |
|---|---|---|
| 标题 | 我在天健熬了十年，最后自己写了个 AI 审计工作台 | 鼎信诺们不肯干的脏活，我一个人干完了！！！ |
| 感叹号 | 6 | 34 |
| 开钩 | 我干了十年上市公司审计。十年。 | 跟各位精神股东汇报一下。 |
| 120 亿那段 | 我不觉得我输。 | 120 亿买不来一个懂审计的产品经理。 |
| 结尾 | 我想吵一点。 | **我想吵一点。**（同句，但前面垫了 34 个感叹号，读感完全不同） |

两版全文见 [`rewritten/`](rewritten/)。

**结论**：同一句结尾，在两档里的效果差别，比任何理论描述都清楚。
选档位的时候，先想清楚你要读者读完是什么表情。
