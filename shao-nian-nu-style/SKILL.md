# 少年怒 写作风格 · Skill 契约

## ⛔ 装载前必须知道的一条

少年怒本人的产品叫「小审同学」，微信 `sjxg1114`，官网 `qiushuict.com`，价格 199-200 元/年。

**这些是他的，不是使用者的。**

范文里出现这些，是因为它们是原文。但你产出的稿子里，产品名、官网、微信、价格
**必须来自使用者提供的《产品档案》**。写错了，等于帮读者给别人的产品打广告——这是本
skill 最容易犯、也最严重的错误。

交稿前自查：全文搜一遍 `小审同学` / `sjxg1114` / `qiushuict`，**必须零命中**。

## 何时用这个 skill

用户说下列任意一句，就该装载它：

- "用少年怒风格重写这篇"
- "帮我把这篇改成少年怒的公众号文风"
- "shao-nian-nu-style"
- "把这份产品介绍稿改成审计江湖体"
- "用少年怒的口吻讲这个功能"

用户显式提到"少年怒"这三个字或引用少年怒公众号链接时，也应主动装载。

## 何时不用

- 严肃合规文书（监管公告、审计报告正文、律师函）
- 上市公司披露、政府文件
- 面向非中文读者的英文稿
- 用户明确要求"专业稳重"、"顾问范"、"官方口吻"

## 装载后必做的三件事

1. **读完 `STYLE_GUIDE.md`**。这是全部规则的正本，不能只看目录。
2. **打开 `examples/` 至少 2 篇范文**（推荐 `01_letter_to_10k_firms.md` + `03_bragging_response.md`），
   感受声音、节奏和金句密度。
3. **读完 `INTENSITY.md`**，确定这次写哪一档（轻度 / 中度 / 重度）。
4. **向使用者要《产品档案》**（下面输入契约里有模板）。没有档案就动笔，必然写串产品。

## 输入契约

### 必需：复刻强度（三选一）

| 档位 | 别名 | 感叹号 | 用在哪 |
|---|---|---|---|
| **轻度 L1** | 借节奏 | 0–3 | 保留原作者声音，只换呼吸。面向客户/合作方/投资人 |
| **中度 L2** | 沉版 | 4–10 | 换成少年怒的声音但压住情绪。原稿内核是回望/自证/复盘时用 |
| **重度 L3** | 冲版 | 15+ | 全盘复刻情绪拉满。自己号、读者是一线同行、要转发量 |

**使用者没指定时**：主动问一句，或默认出**中度**并在交稿时写明「这是中度档，要更冲/更淡说一声」。

⛔ **不要默认出重度**——重度是不可逆的。读者看过一次挑衅版，再发沉版会觉得你怂了。

完整判据、三个风险闸门、真实案例见 [`INTENSITY.md`](INTENSITY.md)。

### 必需：产品档案

```
产品名：        例：审小匠 OpenCPAi
一句话定位：    例：一个可以干活的 AI 审计工作台
官网：          例：https://www.opencpai.com
微信号：        例：xxxxxx
价格：          例：免费试用 / 199 元一年
作者自称：      例：小航 / 小哥 / 老王
作者身份：      例：干了十年上市公司审计，从天健出来的
核心卖点 3-5 条：例：SmartExcel 能读 98% 的烂格式；VLM-OCR 自研不买 API；...
对立面（竞品）： 例：鼎信诺、榕树万千、审查易、审计大师、大所自研插件
```

使用者没给的字段，**留占位 `<待填>`，不要自己编，更不要拿少年怒的顶上**。

### 必需：原料（以下之一）

- 一份**原始稿件**（干货型产品介绍、功能说明、技术自述、创业复盘）
- 一个**话题 + 三五个要点**
- 一份**用户提问**（如"帮我写一篇讲 XX 的公众号"）

## 输出契约

- Markdown 格式，标题在第一行 `# 标题：字数≤30`
- 全文 **1500–3500 字**（少年怒典型长度）
- 至少 **3 个金句独段**（一句话独立成段的爆点）
- 至少 **2 处对立面**（我 vs 大所 / 我的算法 vs 传统插件 / 极致死磕 vs 大厂 AI 之类）
- 结尾**必带推销板块**：产品名 + 官网 + 微信 + 价格，**全部取自《产品档案》**
- **禁止**大段专业术语堆叠、禁止 H3 及以下的深层小标题（少年怒基本不写小标题）

## 验收自查（写完必过）

- [ ] **全文搜 `小审同学`/`sjxg1114`/`qiushuict`，零命中**
- [ ] 通篇没有超过 5 行的长段
- [ ] 感叹号数量落在**本次档位**的区间内（轻度 0–3 / 中度 4–10 / 重度 15+）
- [ ] 至少出现一次这三类比喻：土鸡瓦狗 / 沉没成本 / 白菜价 / 众生平等 / 老六 / 三四层楼那么高 / 砍瓜切菜 / Excel 的牢笼（任选 1 个及以上）
- [ ] 至少一处用了 "TM"、"尼玛"、"老铁"、"小哥"、"同学"、"大家"、"咱们" 中的两个以上
- [ ] 有一个**具体故事**（朋友圈截图、客户对话、员工聊天、自己经历）
- [ ] 有一处**点名或影射同行**（大所 / 八大 / 四大 / 竞品 / 某某互联网大厂）
- [ ] 结尾推销段有价格、官网、微信三件套
- [ ] 情感四拍子（使命 / 挑衅 / 温情 / 自傲）都出现过
- [ ] 交稿时**写明本次是哪一档**，并告诉使用者可以要更冲或更淡
- [ ] 若是**重度档**，额外过三个风险闸门：半点名对象是不是同行软件商（要模糊掉）、有没有脏字（平台限流）、有没有把吹嘘写成时间承诺

## 反面例子（改完千万别像下面这样）

- ❌ "本文将介绍..." / "综上所述..." / "本文旨在..."
- ❌ "第一，第二，第三，..." 议论文腔
- ❌ 冷静客观的第三人称
- ❌ H2 下面还写 H3 / H4 拆得整整齐齐
- ❌ "如需了解更多，请访问官网" 这种官腔
- ❌ **结尾推销的是「小审同学」而不是使用者自己的产品**
