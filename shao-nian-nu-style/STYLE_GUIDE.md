# 少年怒 · 文风蒸馏指南

> 基于 5 篇范文（见 `examples/`）的显式解构。任何写手/LLM 按本文照做，就能出「少年怒」味。

---

## 一、这个作者是谁

- 一个自称"小哥"的 90 后审计从业者，在广东，一毕业进入审计行业将近 10 年
- 20 人团队的老板，做一款叫「小审同学」的审计软件（199-200 元/年/账号）
- 公众号发文频率高，语气介于**朋友圈碎碎念 + 事务所内部群吐槽 + 招商推介**之间
- 情感浓度高：使命感、挑衅感、温情、自傲交替出现，从不平淡

## 二、声音三要素（Voice）

### 2.1 人称系统

| 说到 | 用词 |
|---|---|
| 自己 | "我" / "小哥"（自称）/ 偶尔"小哥我" |
| 团队 | "我们" / "我们的 IT 工程师" |
| 读者 | "大家" / "小伙伴" / "同学" / "老铁" / "各位" |
| 同行/竞争对手 | "他们" / "那些花几千万研发的" / **直接点名或半点名**（某诚、某某互联网大厂、荣某、立某） |
| 产品 | 「小审同学」，永远这样叫，不叫"我们软件"或"这款产品" |

**禁忌**：绝不用"笔者"、"读者朋友们"、"各位看官"这种老式称呼。

### 2.2 情感四拍子

一篇好的少年怒文，会在下面四种情感里循环切换：

1. **使命感**："我要让每一个审计人都能通过努力过上体面的生活。"
2. **挑衅感**："把你们自己的审计软件关了，全部用我的，要不然没得谈。"
3. **温情感**："也坚持过，奋斗过，深爱过。"
4. **自傲感**："我们已经把小审同学做出来了。小审同学目前的功能已经非常优秀。"

**四种情感每篇至少各出现一次**，且**不要连着两段情感相同**——要跳。

### 2.3 语气副词

高频出现，用来加强情绪：

- **绝对**级：绝对、彻底、根本、完全、永远、真的、就是、必须
- **数量**级：所有、每一个、任何一个、100%、98%、99%
- **对比**级：远远、根本、简直、直接、一点点、TM、尼玛
- **决心**级：一定要、必须、就要、非要、非得

## 三、句法特征（Syntax）

### 3.1 断句节奏

- **段落极短**：**1–3 句为一段**，很少超过 5 句。
- **句子极短**：一句话不超过 25 字最舒服。长句必用逗号切碎。
- **单句成段**：金句/爆点单独成段，前后各留空行。

**反例（不要这样写）**：

> 我们的软件在导入功能上做得非常好，无论是科目余额表还是序时账，都能实现自动识别、自动清洗、自动匹配，98% 的账套都能一键导入，只有少数几种特殊格式需要手动干预。

**正例（少年怒会这样写）**：

> 导入功能，我们做到了极致。
>
> 科目余额表、序时账，直接从企业导出来的 excel 就能导。
>
> 不用清洗，不用匹配。
>
> 98% 的账套，一秒钟搞定。
>
> 剩下 2%，我们的软件会告诉你哪一步不对，手动点一下就行。

### 3.2 标点密度

- **感叹号**：至少每 5 段一个。爆点句连打 3 个"！！！"或"！！！！！"是标配。
- **反问号**：结尾往上抛问题，"是不是该引进了呢？""你会信吗？"
- **省略号**：**很少用**。少年怒是直球型，不玩暧昧。
- **破折号**：**不用**。他更喜欢用短句直接切开。

### 3.3 排比与重复

三连的排比是他的常用武器：

> 曾经的我，抱怨过，怀疑过，放弃过。
> 也坚持过，奋斗过，深爱过。

> 功能上，我已经全面超越他们；
> 价格上，我比他们优惠好几倍；
> 他们只想着赚钱；而我，在赚钱的同时，也在做着推动行业发展的事。

**技法**：连续三段用相同起手词、相同句式，最后一段做转折或收束。

### 3.4 反问 + 自答

> 是不是该引进了呢？
> 其实，四大在 2015 年的时候就开始筹备了...

> 为什么选择你的审计软件？
> 我想说：功能上，我已经全面超越他们...

**技法**：把要讲的观点先包装成问题抛出去，然后自己接。这不是修辞——这是把读者拽进对话。

## 四、词汇偏好（Diction）

### 4.1 高频喜爱词

- **牛系**：牛、牛逼、最牛、非常牛、牛的、真牛、牛皮
- **一键系**：一键生成、一键完成、一键搞定、一键汇总
- **秒杀系**：秒杀、秒成、1 秒钟、30 秒、一分钟以内、马上、立刻
- **傻瓜系**：傻瓜式、白痴都会、点一下、不用打字、不用清洗
- **江湖系**：老六、TM、尼玛、老铁、小哥、砍瓜切菜、土鸡瓦狗、独孤求败、赚翻了

### 4.2 高频比喻

- **土鸡瓦狗**（用来贬低对手）："所有的 AI 大模型，在极致的热爱面前，都是土鸡瓦狗。"
- **沉没成本**（用来贬低对手研发投入）："我就是要把这些大所的研发费用，全部干成沉没成本。"
- **三四层楼那么高**（用来吹嘘效率）："让所有人都能花 200 块钱，就能用上效率有三四层楼那么高的审计软件。"
- **白菜价**（用来说自己便宜）："200 元/年/个账号，简直就是白菜价。"
- **网络游戏**（用来说定制化）："就像玩网络游戏一样，谁登录，就是谁的角色，谁的道具。"
- **福特流水线**（用来说效率）："这套流水线工作，其实在 100 多年前的福特公司就开始用了。"
- **老六**（用来自嘲或吐槽同行）："贺姐每次都看到我这个老六。"

### 4.3 独有金句模板

背下来，稍改一下就能用：

1. `所有的 X，在 Y 面前，都是土鸡瓦狗。`
2. `我要让每一个 XX，都能 XX。`
3. `我们的使命，就是 XX。`
4. `X 行业也有一种英雄主义，那就是认清 X 的真相后依然热爱 X。`
5. `以前 X，现在 Y。省下的不是 A，省下的是 B。`
6. `他们那种 X，还怎么跟我们竞争？`
7. `小审同学 + 一个数字（永久免费/200 元/98% 账套）` 组合永远出现。

## 五、结构套路（Structure）

一篇标准的少年怒文，走**开钩—对撞—宣言—推销**四段：

### 5.1 开钩（100–300 字）

在下面三种里挑一种：

- **朋友圈截图 + 客户对话**：贴一张对话截图，讲清背景。
- **自曝生活**："今晚喝了 4 杯白酒，不算多，但也微醺。"
- **一句挑衅**："跟各位精神股东汇报一下近况。"

**目的**：一秒把读者拉进"这是一个活人在跟我说话"的场景里。

### 5.2 对撞（500–1500 字）

制造**我 vs 他们**的对立结构。**他们**通常是：

- 四大 / 八大 / 头部会计师事务所
- 花几千万研发 AI 的大所
- 传统审计软件
- 互联网大厂的 AI 部门
- 到处收集 AI agent 的合伙人

**我**方立场永远是：更快、更便宜、更懂审计、更有使命感。

举证时**必带具体数字**：

- 员工数（20 人 / 3 人）
- 效率倍数（50% / 100% / 三四层楼）
- 价格（199 / 200 元）
- 时间（1 秒 / 30 秒 / 2 分钟 / 1 周）
- 账套覆盖率（98% / 99%）

### 5.3 宣言（100–400 字）

情绪最浓、金句最密的一段。**至少 3 个金句独段**，每段一句话，感叹号连打：

> 我要让审计行业，不再意味着：加班、工资低。
>
> 我要让每一个审计人，都能通过努力过上体面的生活。
>
> 审计行业的 AI，我来搞！

### 5.4 推销（200–800 字）

必带三件套：

1. **产品名 + 官网**：`小审同学 · https://www.qiushuict.com/`
2. **微信号**：`sjxg1114`
3. **价格**：`199-200 元/年/账号`

再加上**试用承诺**："永久免费试用，想试用多久就试用多久。"

如果有**多套卖点**，就编号 1/2/3/4/... 列出来（例：软件、合并课程、excel 课程、底稿课程）。

## 六、六条硬规范（Six Hard Rules）

改稿时逐条对照，不达标就重写：

1. **不写小标题** — 少年怒的公众号里几乎不用 H2/H3，用**空行 + 短句**做分隔；如果非要用，最多用几个 H2 分大段。
2. **不写议论文** — 禁用"第一/第二/第三"、"综上所述"、"由此可见"这种。
3. **不做客观陈述** — 每段都要有**情感或立场**；干巴巴的功能描述必须包一层"我们做到了""他们做不到"。
4. **不用官腔** — 禁用"如需了解更多"、"欢迎咨询"、"敬请关注"。改用"想试用的兄弟直接加我微信"。
5. **每篇至少一个具体故事** — 客户对话 / 朋友圈截图 / 自己十年前的经历 / 员工聊天。
6. **每篇必带推销三件套** — 产品名、官网、微信号、价格中至少 3 项。

## 八、少年怒 vs 你自己的产品文（对照表）

假设你有一份**冷静的功能介绍稿**，要改成少年怒风格：

| 冷静版说法 | 少年怒版说法 |
|---|---|
| 本功能可显著提升审计员的工作效率 | 这个功能，直接把审计员的效率干上三四层楼 |
| 系统支持自动识别科目余额表 | 我们训练了 98% 的账套，一键就导进去，不用清洗 |
| 传统方式需要 15 分钟的人工核对 | 以前要 15 分钟人工瞪眼核对，眼睛都要瞪瞎 |
| 相比市面同类产品，本产品有以下优势 | 我把话撂这儿：市面上没有一款审计软件比我们牛 |
| 定价 199 元/账号/年，具备较高性价比 | 200 元一年，简直就是白菜价 |
| 如需试用，请访问官网下载 | 想试用的兄弟直接加我微信 sjxg1114，我发安装包 |
| 综上所述，本产品能有效降本增效 | 用了小审同学，年审再也不难做了！！！ |

## 九、写完后的自检清单（Copy-Paste 用）

```
[ ] 通篇没有超过 5 行的长段
[ ] 感叹号 ≥ 15 个（正文，不含标题）
[ ] 用了这些比喻至少 1 个：土鸡瓦狗 / 沉没成本 / 白菜价 / 众生平等 / 老六 / 三四层楼 / 砍瓜切菜
[ ] 出现下列口头禅至少 2 类：TM / 尼玛 / 老铁 / 小哥 / 同学 / 大家 / 咱们
[ ] 有一个具体故事（朋友圈截图 / 客户对话 / 员工聊天 / 自己经历）
[ ] 至少 1 处点名/影射同行（大所 / 八大 / 四大 / 某诚 / 某某互联网大厂）
[ ] 至少 3 个金句独段
[ ] 结尾推销段有：产品名 + 官网 + 微信 + 价格 中的 3 项及以上
[ ] 全文 1500–3500 字
[ ] 情感四拍子（使命 / 挑衅 / 温情 / 自傲）都出现过
```

10 条打勾 ≥ 8 项，才算合格少年怒。

## 十、边界与忌讳

- **不涉政、不涉宗教、不涉具体人身攻击**。少年怒骂的是"某诚""某互联网大厂""大所"，不是骂具体自然人。
- **不造谣同行数据**。"某所每年花几千万研发 AI" 这种说法可以，但不能写"某所去年亏损 5 亿"这种造谣。
- **不涉执业内容**。少年怒是**软件老板 + 审计从业者**，不是审计师意见发布者。写产品可以吹，写审计程序要有分寸。
- **不涉客户名单**。凡涉具体客户，一律匿名或用"某集团"、"广西排名第一的所"。

---

**最后一句**：少年怒的写作，本质是**一个真诚的人在爆点情绪**。不是模仿他的词，是模仿他**敢说、敢喷、敢自吹、敢自嘲**的那种松弛感。你越较真儿地"完成任务"，越写不像。
